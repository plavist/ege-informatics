1. 
(А. Шуруха) Исполнитель преобразует число на экране. У исполнителя есть три команды, которые обозначены латинскими буквами:
A. Прибавь 1
B. Прибавь 3
C. Замени цифру
Первая команда увеличивает число на экране на 1. Вторая команда увеличивает число на экране на 3. Третья команда применяется
только к числу, в записи которого присутствует хотя бы одна цифра 1, и действует, заменяя число на экране числом, в котором
каждая цифра 1 заменена на цифру 3.
Программа для исполнителя — это последовательность команд.
Сколько существует программ, для которых при исходном числе 11 результатом является число 94, и при этом никакие две
одинаковые команды не идут подряд?
Траектория вычислений программы — это последовательность результатов выполнения всех команд программы.
Например, для программы ABC при исходном числе 11 траектория состоит из чисел 12, 15, 35.

2.
Исполнитель преобразует число на экране.
У исполнителя есть три команды, которые обозначены латинскими буквами:
A. Прибавить 1
B. Умножить на 2
C. Умножить на 3
Программа для исполнителя – это последовательность команд.
Сколько существует программ, для которых при исходном числе 2 результатом является 39 и при этом траектория вычислений не содержит числа 14?
Траектория вычислений программы – это последовательность результатов выполнения всех команд программы.
Например, для программы ABC при исходном числе 7 траектория состоит из чисел 8, 16, 48.
